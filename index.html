Research areas

ML ⇄ Systems
01 · Current

Agentic workflows for scientific discovery

How can AI agents turn a scientist's natural-language goal into a workflow, then decide where every step should run across local machines and remote HPC clusters, using live system conditions?

LLM agentsWorkflow synthesisHPC schedulingIntrospection
MARGE / SciAgents — jointly synthesizes workflow DAGs and maps tasks to resources as a constrained optimization problem, with a dual-variable refinement layer. Up to 83.78% lower makespan.
02 · Current

ML compilers & GPU kernel tuning

Where do compiler defaults leave performance on the table, and is the gap about choosing configurations or about backend code generation?

IREE / MLIRGEMM autotuningRoofline analysisCost models
Empirical GEMM-tuning study — tuned vs. default IREE codegen on NVIDIA A100 and AMD MI300X, including LLM-decode shapes and a cross-version SharkTuner comparison.
03

Performance modeling with transfer & few-shot learning

Can we predict application performance on new hardware, or even quantum-HPC systems, from only a few samples by transferring knowledge across heterogeneous datasets?

Transfer learningFew-shot learningAttention modelsCross-platform
